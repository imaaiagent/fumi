# Contributing

Thanks for helping build FUMI.

## Pull requests

- Keep changes focused.
- Explain how you tested them.
- Do not commit credentials or private data.
- Keep public documentation in English.
- Clearly label results as compiled, simulated, hardware-tested, or end-to-end tested.

## Firmware reports

Include:

- board revision
- Arduino IDE version
- ESP32 core version
- relevant library versions
- exact reproduction steps
- sanitized Serial Monitor output

Never include Wi-Fi passwords, API keys, tokens, or private conversations.
