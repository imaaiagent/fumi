# FUMI Demo

## Backend demo

1. Start the backend.
2. Open `demo/index.html`.
3. Enter the backend URL.
4. Send a message.
5. Confirm the response shows the configured provider/model.

## Hardware demo

For the public repository, add a real video such as:

`docs/assets/fumi-demo.mp4`

The video should show the physical FUMI device, not a simulated animation.

Recommended sequence:

- boot
- idle animation
- touch interaction
- open AI/chat interaction
- AI response
- push-to-talk voice
- voice response

If the public repository does not yet contain a video, do not claim "end-to-end verified" in the README. Mark the component as "hardware-tested" only after a real device test.
